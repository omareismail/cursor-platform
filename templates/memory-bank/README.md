# Installable memory-bank templates

Copy these into an **adopter** repository. Do not replace
`cursor-platform`'s own `memory-bank/` — that folder is this product's live
Tier 1/Tier 2 context, not a template.

The platform checkout keeps real `activeContext.md` / `progress.md` here in
the repo root `memory-bank/`. Adopters start from the files under
`memory-bank/` in a new project playbook (see `.cursor/docs/NEW-PROJECT.md`).
