- [x] **The P2G-1 assertion was pinning Windows behaviour on Linux.** `write.test.mjs` asserted that `guard-write` refuses `root + "\.cursor\mcp-policy.json"`. On POSIX a backslash is a legal filename character rather than a separator, so that payload names a different file and refusing it would be the bug. - [x] **ROOT CAUSE, CONFIRMED — the CLI guard compares a hand-built `file://` URL.** Four tools decided whether to run their CLI with `import.meta.url === new URL(\`file://${process.argv[1]...}\`).href`. `import.meta.url` percent-encodes a tilde as `%7E` and the hand-built URL leaves it literal, so **on any path containing a tilde the guard is false, the CLI never runs, and the tool exits 0 having printed nothing** — which reads downstream as a tool that succeeded and found nothing. Windows 8.3 short names are made of tildes, and the CI runner's temp directory has one. Reproduced locally by invoking a tool through its 8.3 spelling: silence before, full envelope after. **Not a test bug** — any Windows adopter whose user name exceeds eight characters can hit it, since `%TEMP%` is commonly the 8.3 form, and `ac-trace`, `artifact-schema`, `memory-bank` and `lifecycle` would all go quiet. Fixed in the three unprotected tools (`3a3052e`); `ac-trace.test.mjs` went green on the next run, which is what confirmed it.

(2) *An empty or absent fixture copy*: `node <empty file>` gives exit 0 with both streams empty, an exact match for the symptom. Refuted by instrumenting rather than guessing again — the next log printed `script 28829 bytes`.
